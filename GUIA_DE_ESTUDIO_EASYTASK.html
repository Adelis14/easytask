1. Introducción y Propósito del Proyecto

EasyTask es un sistema integral de gestión y seguimiento diseñado para transformar los acuerdos discutidos en reuniones y sesiones de trabajo en tareas concretas, medibles y auditables.

Problema central que resuelve: En la mayoría de las organizaciones, las reuniones concluyen con acuerdos informales que se olvidan o quedan archivados en notas estáticas ("muerte por reunión"). EasyTask convierte cada acta formal (minuta) en un flujo visual interactivo con responsables, fechas de entrega y estado de avance en tiempo real.

2. El Flujo Visual de Tareas

El sistema se fundamenta en un modelo de clasificación cromática intuitiva que permite a cualquier usuario o directivo conocer la situación del equipo en un segundo:

🔴 Rojo (Iniciado / Urgente)

Identifica tareas recién pactadas, acuerdos pendientes de arranque o tareas que requieren atención inmediata y prioritaria.

🟡 Amarillo (En Proceso)

Identifica tareas con trabajo activo en ejecución y avances constantes en curso.

🟢 Verde (Listo / Completado)

Identifica tareas concluidas con éxito, validadas y entregadas satisfactoriamente.

Interacción en las Tarjetas de Tarea:

Cada tarjeta dentro del tablero cuenta con un círculo indicador del color activo junto a un selector desplegable (select). El usuario puede cambiar directamente el color de la tarea, lo que actualiza su estado en la base de datos de manera instantánea y transparente.

3. Módulos y Navegación del Sistema

La aplicación está dividida en páginas desacopladas mediante React Router, garantizando una navegación rápida, ordenada y sin recargas de pantalla:

1. Dashboard General (/) Panel de control con métricas clave: total de tareas, conteo de tareas en rojo, amarillo y verde, tasa global de conclusión y accesos directos a todos los módulos.
2. Tablero de Tareas (/compromisos) Vista de flujo visual en 3 columnas principales (Rojo, Amarillo, Verde). Incluye filtros rápidos por color, barra de búsqueda por responsable o título, puntos de control (subtareas) y modal para pactar nuevas tareas.
3. Agenda de Reuniones (/reuniones) Planificación y calendario de sesiones de trabajo con fecha, hora, modalidad (videoconferencia o presencial) y enlace directo a su acta de acuerdos.
4. Gestión de Minutas (/minutas) Repositorio formal de actas donde se documentan los acuerdos formalizados. Permite crear nuevas minutas y vincularlas directamente a las tareas del tablero.
5. Directorio de Usuarios (/usuarios) Control del equipo de trabajo. Muestra el número de tareas asignadas a cada colaborador, tareas listas, tareas en rojo y su tasa individual de resolución. Además, incluye la función para crear nuevos usuarios dentro del sistema estando autenticado.
6. Portafolio de Proyectos (/proyectos) Iniciativas estratégicas a largo plazo que agrupan y articulan múltiples minutas y tareas del equipo.

4. Glosario y Conceptos Técnicos del Sistema

A continuación se explican los términos técnicos utilizados en la arquitectura para facilitar su comprensión y defensa:

Término Definición Técnica Aplicación Práctica en EasyTask
SLA (Service Level Agreement) Acuerdo de Nivel de Servicio. Estándar de calidad y límite de tiempo acordado para responder o entregar una tarea. El backend garantiza tiempos de respuesta de consulta ultrarrápidos y el sistema detecta cuándo una tarea requiere atención prioritaria antes de su fecha límite.
SPA (Single Page Application) Aplicación de Página Única. La aplicación web no recarga la página completa al hacer clic, sino que refresca los componentes al instante. El usuario disfruta de una experiencia fluida e inmediata al navegar entre el Dashboard, Tareas, Minutas y Usuarios sin parpadeos blancos.
Kanban Metodología visual japonesa de gestión de trabajo organizada en columnas secuenciales de progreso. Estructura el tablero de tareas en columnas de flujo (Rojo, Amarillo y Verde) para identificar cuellos de botella de inmediato.
ORM & Sequelize Mapeador Objeto-Relacional que traduce objetos en JavaScript a sentencias SQL seguras en la base de datos. Al encender el servidor, Sequelize revisa la base de datos y crea automáticamente todas las tablas necesarias sin necesidad de scripts manuales.
Pool de Conexiones Gestor que mantiene conexiones abiertas listas para ser reutilizadas por múltiples usuarios a la vez. Permite que varios directivos y colaboradores usen el sistema concurrentemente sin que la aplicación se ponga lenta.
JWT (JSON Web Token) Credencial digital cifrada y firmada que valida la identidad del usuario en cada solicitud. Protege las rutas privadas del sistema para que personas no autorizadas no puedan acceder a la información de las minutas.
Auditoría Inmutable (Audit Trail) Registro histórico inalterable de cada cambio realizado sobre un registro. Guarda quién cambió el estado de una tarea, la fecha y hora exacta, accesible desde el botón de historial en cada tarjeta.

5. Preguntas Clave para Defensa y Presentación

¿Cómo se garantiza que la base de datos se configure sola sin intervención manual?

Gracias al ORM Sequelize y su instrucción de arranque sequelize.sync({ alter: true }) en el archivo principal del servidor. Al iniciar el proyecto, Sequelize verifica si existen las tablas de usuarios, tableros, tareas e historial; si no existen, las crea automáticamente con sus tipos de datos y relaciones.

¿Cómo se resolvió la saturación de pantallas del código anterior?

El frontend anterior tenía 2074 líneas en un solo archivo monolítico, lo que provocaba que el menú mezclara secciones. Se aplicó una arquitectura desacoplada con react-router-dom y un componente de navegación compartido (Layout), separando cada funcionalidad en su propia vista.

¿Cómo interactúa el usuario con los colores de las tareas?

Cada tarjeta presenta un indicador circular del color actual y un menú desplegable (select) donde el usuario puede alternar con un solo clic entre Rojo (Iniciado), Amarillo (En Proceso) o Verde (Listo).

¿Se pueden registrar usuarios tanto desde afuera como estando adentro?

Sí. En la pantalla de inicio de sesión existe la opción "Crear Cuenta", y dentro del sistema, en la página de Usuarios, el administrador dispone del botón "+ Nuevo Usuario" para registrar colaboradores directamente sin cerrar su sesión.
